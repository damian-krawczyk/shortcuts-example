# macOS
version: 15 Sequoia

- [x] `Cmd+Space` Spotlight — search apps, files and the web
  tags: #search
- [ ] `Shift+Cmd+4` Screenshot of a selection
  tags: #screenshot

## Finder

- [x] `Shift+Cmd+.` Show / hide hidden files
- [ ] `Alt+Cmd+C` Copy the path of the selected item

## VS Code
version: 1.95

- [x] `Shift+Cmd+P` / `F1` Command Palette — run any command
  tags: #essential
- [ ] `Cmd+K Cmd+S` Keyboard Shortcuts editor
  version: 1.90+

### Editing

- [x] `Cmd+D` Add the next match to the selection
  tags: #multi-cursor
- [ ] `Alt+Up` / `Alt+Down` Move line up / down

# Linux

## Terminal

- [x] `Ctrl+R` Search the command history
  tags: #terminal
- [ ] `Ctrl+A` / `Ctrl+E` Go to the start / end of the line — in bash and zsh
  tags: #terminal
  Uses the default Emacs-style key bindings;
  run `set -o vi` and they stop working.
